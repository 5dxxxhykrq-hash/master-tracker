# Master's Application Tracker

A responsive, browser-persistent tracker for six European business master's applications for 2027 entry.

## Features

- Application timeline with confirmed vs pending dates
- One workspace per programme
- Status controls for CV, motivation letter, references, IELTS, portal, assessments and submission
- Final submission date and notes
- Local browser persistence
- Official source links and explicit uncertainty labels

The deployable static site is in `dist/`.
